# 五子棋 (Gomoku / Five-in-a-Row)

C/C++ 课程设计 —— 基于 **Win32 API + GDI/GDI+** 的五子棋游戏，单文件实现（`gomoku.cpp`），无第三方依赖。

## 功能特性

- **菜单页面**：双人对战 / 人机对战 两种模式选择
- **传统木纹棋盘**：19×19 标准棋位，黑白交替落子，五连判胜
- **AI 对手**：贪心算法 + 估值函数（进攻 / 防守加权），人机模式 AI 执白
- **游戏按钮**：认输、悔棋、再开一局、返回菜单
- **视觉效果**：水墨背景图片 + 标题图片，双缓冲渲染防闪烁
- **音效**：背景音乐（循环播放）+ 落子点击音效

## 快捷键

| 按键 | 功能 |
| ---- | ---- |
| `R` | 重新开始一局 |
| `Esc` | 返回主菜单 |

## 核心函数说明

`gomoku.cpp` 单文件约 1100 行，函数按功能分为五组：

### 1. 游戏逻辑

| 函数 | 说明 |
| ---- | ---- |
| `InitGame(mode)` | 初始化一局游戏：清空棋盘、重置手数、当前玩家（黑先）、胜负状态等 |
| `CheckWin(x, y, player)` | 落子后判胜：从刚下的 (x,y) 出发，沿横、竖、两条斜线共 4 个方向数连子，≥5 即获胜 |
| `EvaluatePos(x, y, player)` | AI 的估值函数：假设 player 下在 (x,y)，按四个方向的连子数和"封堵端"数打分（活四 10000 > 冲四 1000 > 活三 500 ……） |
| `AITurn()` | AI 落子决策：棋盘为空时直接下天元；否则只考察已有棋子周围 2 格内的空位，对每个空位算「进攻分 × 1.2 + 防守分」，取最高分落子（贪心策略） |

### 2. 音效

| 函数 | 说明 |
| ---- | ---- |
| `StartBGM()` | 用 `mciSendString` 循环播放 `bgm.mp3`（找不到时退回 `bgm.wav`） |
| `StopBGM()` | 停止并关闭背景音乐 |
| `PlayClickSound()` | 播放落子 / 点击音效 `click.wav` |

### 3. 图片与背景

| 函数 | 说明 |
| ---- | ---- |
| `LoadBgImage()` | 初始化 GDI+，依次尝试加载 `bg.jpg` / `bg.jpeg` / `bg.png` / `bg.bmp` 作背景，同时加载标题图 `bt_title.png`（或 `bt.png`） |
| `FreeBgImage()` | 释放图片资源和 GDI+ 环境 |
| `RebuildBgBmp(w, h, hdc)` | 把背景图按窗口大小等比缩放（覆盖式裁剪），预绘制到一张兼容位图缓存起来，避免每帧重复缩放 |
| `DrawBackground(hdc, w, h)` | 把缓存的背景位图一次性贴到窗口；没有图片时用纯色画刷兜底 |

### 4. 界面绘制

| 函数 | 说明 |
| ---- | ---- |
| `LayoutBoard(w, h)` / `LayoutButtons(w, h)` | 根据窗口客户区大小，计算棋盘的位置、格宽和四个按钮的区域（窗口缩放时界面自适应） |
| `DrawMenu(hdc, w, h)` | 绘制主菜单：背景、标题图片、「双人对战 / 人机对战」两个按钮（含鼠标悬停高亮） |
| `DrawBoard(hdc)` | 绘制棋盘：木色底、19×19 网格线、9 个星位 |
| `DrawStone(hdc, x, y, player)` | 绘制棋子：黑子带灰色高光，白子用多层同心圆模拟渐变+高光，均带投影，立体感效果 |
| `DrawGame(hdc, w, h)` | 绘制游戏页：背景 → 棋盘 → 全部棋子 → 最后一手红点标记 → 底部四个按钮（认输 / 悔棋 / 再开一局 / 返回菜单） |
| `DrawCenteredText(hdc, ...)` | 工具函数：在指定矩形内居中绘制文字 |
| `DoPaint(hwnd)` | 总绘制入口：先画到内存位图，再一次拷贝到窗口（**双缓冲**，防止闪烁） |

### 5. 窗口与消息

| 函数 | 说明 |
| ---- | ---- |
| `WndProc(...)` | 窗口过程，处理所有消息：鼠标移动（按钮悬停高亮）、鼠标点击（菜单选模式、棋盘落子、按钮）、键盘（R 重开 / Esc 返回菜单）、窗口重绘与缩放等 |
| `wWinMain(...)` | 程序入口：注册窗口类、创建窗口、进入消息循环，程序启动时加载图片并播放 BGM |

> AI 策略一句话总结：**每步都选"自己得分 × 1.2 + 对手得分"最高的点**——稍微偏进攻，能堵对手活三/冲四，也会自己抢连子。

## 运行环境

> **⚠️ 强烈建议只在 Dev-C++ 中打开和运行本项目！**
>
> 本项目使用纯 Win32 API + GDI+ 编写，依赖 MinGW（TDM-GCC）编译环境。Dev-C++ 自带该环境，开箱即用；
> 而 **VS Code 配置起来较为麻烦**（需要自行安装配置 MinGW 编译器、解决 GDI+ / winmm 等库的链接问题），不推荐使用。

### 在 Dev-C++ 中运行

1. 用 Dev-C++ 打开 `gomoku.cpp`，**先另存为 / 编译到本项目目录**（保证 `bg.jpg`、`bgm.mp3` 等资源文件和 exe 在同一目录，否则无背景和音效）。
2. 打开菜单 **工具 → 编译选项**，做两处设置：

   **① 编译器 → "编译时加入以下命令" 中填入**（来自 `命令.txt` 第 1 行）：

   ```
   -finput-charset=UTF-8 -fexec-charset=GBK
   ```

   **② 连接器 → "连接时加入以下命令" 中填入**（来自 `命令.txt` 第 2 行）：

   ```
   -lgdiplus -lwinmm -lole32 -loleaut32 -lgdi32 -luser32 -mwindows -municode -static-libgcc
   ```

3. 保存设置后，按 **F11**（编译并运行）即可。

### 各编译参数的作用

| 参数 | 作用 |
| ---- | ---- |
| `-finput-charset=UTF-8 -fexec-charset=GBK` | 源码为 UTF-8 编码，编译后运行时中文正常显示（解决乱码） |
| `-lgdiplus` | 链接 GDI+，用于加载 jpg / png 图片 |
| `-lwinmm` | 链接多媒体库，播放 mp3 / wav 音频 |
| `-lole32 -loleaut32` | OLE/COM 支持，配合图片加载 |
| `-lgdi32 -luser32` | GDI 绘图与窗口支持 |
| `-mwindows` | Windows 窗口程序（不弹出黑色控制台） |
| `-municode` | 使用 Unicode（`wWinMain`）入口 |
| `-static-libgcc` | 静态链接 GCC 运行库，exe 可单独分发 |

## 玩法

- 黑棋先行，双方交替落子，任意方向（横、竖、斜）先连成五子者获胜。
- 人机模式下玩家执黑，AI 执白。
- 支持悔棋（人机模式悔棋会同时撤销 AI 和玩家各一步）。
